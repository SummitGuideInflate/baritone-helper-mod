## 📖 About

Baritone Helper provides a clean GUI for the Baritone pathfinding library, letting you queue mining, gathering, building, and travel tasks without command-line input.

---

## ✨ Features
<a name="features"></a>

- **Task Queue** — queue multiple Baritone goals in order.
- **GUI Goal Setter** — click-to-set target block or coordinate.
- **Mining Mode** — configure target ores and depth range.
- **Build Mode** — load schematic for Baritone to build.
- **Status HUD** — live Baritone state and current goal.
- **Pause/Resume** — one key to halt and continue.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
